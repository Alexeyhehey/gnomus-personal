# Гномус с телефона

Как это работает (объясни ей одной фразой): «Я продолжаю жить на твоём компьютере, а телефон становится пультом — ты пишешь мне с телефона, я работаю здесь, со всей памятью».

Основа — функция Remote Control приложения Claude: доступна на подписке Pro, сессия работает на ПК, телефон ею управляет. Источник: https://code.claude.com/docs/en/remote-control.md (проверено 17.11.2026; если шаги не совпадают с тем, что она видит, — проверь страницу заново).

## Шаги (веди её по одному, после каждого — «получилось?» кнопками)
**На компьютере**
1. В приложении Claude открыть настройки: Settings → Code (или Settings → Claude Code) → включить «Connect new sessions to Remote Control». Если пункт не найден — в открытой сессии написать `/remote-control`.
2. Компьютер не должен засыпать, пока она хочет писать с телефона. Проверь текущие настройки сна (`powercfg /q`) и, если он засыпает от сети раньше чем через 2 часа, спроси кнопкой: «не давать компьютеру засыпать, пока он в розетке?». По её «да» — `powercfg /change standby-timeout-ac 0`. Экран может гаснуть — это не мешает. Запиши в `life/journal.md`, что поменял и как вернуть (`powercfg /change standby-timeout-ac <минуты>`).
3. Приложение Claude не закрывать (свернуть можно).

**На телефоне**
4. Установить приложение Claude (App Store или Google Play), войти тем же аккаунтом, что на компьютере.
5. Открыть в приложении вкладку Code — там будет сессия с иконкой компьютера и зелёным кружком. Ещё проще: в сессии на компьютере написать `/mobile` и отсканировать QR-код телефоном.
6. Проверка: она пишет с телефона «привет с телефона» — ты отвечаешь.

## Что сказать ей про ограничения
- Компьютер должен быть включён и не спать, приложение Claude — открыто.
- Если ты задашь вопрос кнопками, а она не ответит за несколько минут, вопрос пропадёт — тогда просто напишет ответ словами.
- Переписка проходит через серверы Anthropic (как и обычный чат с Claude); файлы остаются на её компьютере.
- Альтернатива для новых задач с телефона — функция Dispatch в мобильном приложении (тоже Pro): https://code.claude.com/docs/en/desktop.md#sessions-from-dispatch

Запиши в `profile.md` → «Модули»: «телефон, <дата>».
