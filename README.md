# Личный Гномус

Помощник для жизни на Claude Code: здоровье и лекарства, деньги и заработок, работа, документы, идеи.
Живёт на компьютере человека, помнит всё в файлах у него же, работает по его собственной подписке Claude.

Этот репозиторий — источник обновлений. Гномус обновляется сам по фразе «обнови себя»:
скачивает `latest.json`, затем архив версии, и ставит только новое и неизменённое —
память человека (`life/`) и его правки не трогаются никогда.

- `latest.json` — какая версия последняя и как называется её архив.
- `gnomus-personal-<версия>.zip` — комплект: прошивка, навыки, инструменты, `install.ps1`, `update.ps1`, `manifest.json` с отпечатками файлов.
- `kit/` — то же содержимое в распакованном виде, чтобы было видно, что внутри.

Установка сейчас — вместе с автором. Подписку Claude человек покупает у Anthropic сам и сам входит в свой аккаунт.
